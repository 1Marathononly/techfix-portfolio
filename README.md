# TechFix Portfolio

A responsive landing page for TechFix, offering phone and laptop repairs,
software support, web development, and graphic design.

## Preview

Open `Asset/pages/Assignment.html` in a browser. The page uses plain HTML, CSS,
and JavaScript and does not require a build step.

## Contact

The contact form opens WhatsApp with the visitor's details and message
pre-filled. The contact number is configured in `Asset/pages/Assignment.html`
and `Asset/pages/Assignment.js`.
